# Ethan's Crane Game

Open `index.html` in your web browser to play. Use the arrow keys to move the
crane. Press the space bar to close the claw and try to grab a seal; press it
again to drop a held seal into the prize chute. The graffiti covered cabinet
holds several plush seals and the game wins about one in every four attempts.
Electronic tones play in the background and short sounds signal win or lose
actions.
